# Байесовские сети

Задания по предмету «Основы вероятностного моделирования». Каждая задача решена в Python (библиотека [pgmpy](https://pgmpy.org/)) и продублирована в UnBBayes.

| Задача | Что ищем | Ответ |
| --- | --- | --- |
| [Погода](weather/) | P(высокая влажность), P(солнечно \| высокая влажность) | 0.514, 0.358 |
| [Метеорит](meteor/) | P(уничтожение человечества) | 0.6937056 |

В каждой папке:

- `*_bn.ipynb` — ноутбук для Google Colab: структура сети, таблицы вероятностей, вывод, визуализация;
- `*.net` — сеть в формате Hugin, открывается в UnBBayes через File → Open;
- `network.png` — визуализация сети с априорными вероятностями.

Запуск: открыть ноутбук в Colab (Файл → Загрузить блокнот) и выполнить все ячейки (Ctrl+F9).
